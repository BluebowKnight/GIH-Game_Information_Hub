# 宝可梦简中卡牌情报站

五个常驻栏目的宝可梦集换式卡牌游戏（简体中文版）情报站。纯静态网页，数据全部抓取自 **宝可梦中国官方网站（www.pokemon.cn）**。

## 栏目与官方数据源

| 栏目 | 内容 | 官方来源 |
|---|---|---|
| 新品 / 上新 | 只收录**近 3 个月内**的上新商品（补充包 / 构筑卡组 / 礼盒套装 / 周边道具），默认展示其中**尚未发售**的部分，不含周边资讯；随附周边（冰箱贴、徽章、磁吸贴等）单独打标签；近 3 个月内已发售的默认收纳、可一键展开对照 | 官网「商品一览」 |
| 活动 / 赛事 | 进行中 / 即将开始的官方赛事与活动，标注活动起止日期与**活动简介**（人工总结 + 正文自动提炼，重点说明参加后能获得什么）；**只展示最近 2 个月内**的，默认显示**最新 5 条**、其余收起可一键展开；**不收录**报名批次通知与已结束活动 | 官网「集换式卡牌游戏」资讯（Event 类） |
| 牌店 / 快闪 | 官方卡牌道馆名录（营业时间 / 地址），默认显示**前 3 行**（按当前网格列数动态计算，宽屏 9 家 / 窄屏 3 家）、其余收起可展开（搜索时自动展示全部匹配结果）+ 即将开店预告；**点击道馆卡片**弹窗展示该馆的**限定商品**（冰箱贴 / 钥匙扣 / 卡组收纳盒 / 艺术卡套 / 环保购物袋）与**开业特典** | 官网「店铺」页（道馆名录）+ [52poke 百科](https://wiki.52poke.com/zh-hant/%E5%AF%B6%E5%8F%AF%E5%A4%A2%E5%AE%98%E6%96%B9%E5%8D%A1%E7%89%8C%E9%81%93%E9%A4%A8)（限定商品，人工维护） |
| 环境牌组 | 简中**标准赛制**主流牌组环境分析：使用率 / 表现分占比 / 转换比排行（默认 **Top 5**，其余收起可展开）+ **本期研判** + **三套核心牌组拆解**（打法 / 优势 / 短板 / 对局）+ **怎么选 · 按投入程度分轻 / 中 / 重三档**；**点牌组名**查看完整分析 | 量化数据取自 AREAZERO.GG 卡组统计（数据源于官方赛事）；潜力与建议为人工研判 |
| 版本 / 赛制 | 标准赛制与开放赛制的可用标记、例外卡牌、禁用卡牌，以及**最新一条**赛制调整公告 | 官网「赛制」页面 |

> 关于「环境牌组」的口径：
> - **量化数据**来自 [AREAZERO.GG 卡组统计](https://tcg.mik.moe/decks)——简中唯一公开量化环境源。
>   其统计对象是**获得表现分的卡组**，表现分依据官方完赛排名与参赛人数换算，
>   比单纯统计夺冠更少受头部失真影响；团队赛 / 多卡组赛按卡组份数加权。
>   该站为 React 单页应用，普通请求抓不到内容，需浏览器渲染后读取，抓取前已取得站点授权同意。
> - **核心指标「转换比」= 表现分占比 ÷ 使用率**：> 1 表示「用的人相对少、赢得相对多」，
>   属被低估的高潜力牌组；< 1 表示使用率高于实际战绩，属过热。仅对样本量 ≥ 20 的牌组计算。
> - **潜力分析**为人工研判，结论先行、理由随后、风险单独标注；官方未公布的日期一律标注「推测」。
>   本栏目**不做卡价与收卡建议**。
> - 潜力判断以**标准赛制**为主，同时会提示退环境风险。
> - 「行动建议」按**投入程度**分轻 / 中 / 重三档（投入指时间、练习量与组牌难度），
>   只做环境与强度分析，**不涉及卡价与收卡建议**。
>
> 分析底稿存放在 `scripts/meta_analysis.json`，可人工按最新环境更新；
> 抓取脚本每次运行会把它并入 `data/data.json` 的 `decks.analysis`。

> 关于「冰箱贴」等小周边：官网网页版没有独立的冰箱贴商品条目，只在礼盒商品的「商品内容」中
> 出现（已自动打标签，如 30 周年收藏展示礼盒、中秋礼盒），部分周边上新仅通过官方微博 / 小程序发布。

> 关于「道馆限定商品」：每家官方卡牌道馆都有对应主题宝可梦的限定商品（冰箱贴 / 钥匙扣 /
> 卡组收纳盒 / 艺术卡套 / 环保购物袋 L·M·S），以及独有开业特典（多为特典卡，部分为书签等）。
> 官方店铺页只有营业时间与地址，**没有**限定商品信息，因此这部分数据来自
> [52poke 百科](https://wiki.52poke.com/zh-hant/%E5%AF%B6%E5%8F%AF%E5%A4%A2%E5%AE%98%E6%96%B9%E5%8D%A1%E7%89%8C%E9%81%93%E9%A4%A8)，
> 存放在 `scripts/gym_exclusives.json`，按吉祥物名称匹配注入每家道馆，人工维护更新。

## 目录结构

```
情报合集仓库根目录
├── index.html                    # 合集首页（入口门户）
└── pokemon-tcg-cn/               # 宝可梦卡牌情报站（子站）
    ├── ptcg.html                 # 情报站页面（五个栏目）
    ├── assets/
    │   ├── style.css             # 样式
    │   ├── app.js                # 前端渲染逻辑
    │   └── img/                  # 本地化图片（webp，抓取时生成）
    ├── data/
    │   ├── data.json             # 结构化数据（抓取生成）
    │   └── data.js              # window.PB_DATA（供 <script> 直接加载）
    └── scripts/
        ├── fetch_data.py         # 官方数据抓取脚本（核心）
        ├── event_summaries.json  # 人工撰写的活动简介
        ├── meta_analysis.json    # 环境牌组分析底稿
        └── gym_exclusives.json   # 道馆限定商品底稿（52poke 百科）
```

## 本地使用

```bash
cd pokemon-tcg-cn

# 抓取最新数据（写入 data/ 与 assets/img/）
python3 scripts/fetch_data.py

# 本地预览
python3 -m http.server 8099
# 打开 http://127.0.0.1:8099/        ← 合集首页
# 打开 http://127.0.0.1:8099/pokemon-tcg-cn/ptcg.html  ← 情报站
```

依赖：Python 3.8+、`pillow`（图片压缩，缺失时自动跳过图片下载）。

## 技术说明

- 官网图片 URL 带时效签名（`auth_key`），数小时后失效，因此抓取脚本会把图片下载并压缩为
  webp 存到 `assets/img/`，网页只引用本地图片；文件名哈希基于去签名 URL，重复抓取不会重复下载。
- 活动简介：优先采用 `scripts/event_summaries.json` 里人工撰写的总结（重点写「参加后能获得什么」）；
  新出现、尚未收录的活动自动从官方正文里挑奖励 / 特典卡 / 积分相关的句子提炼，不会留空。
- 脚本内置健康检查：任一核心栏目抓取为空时以非 0 退出，避免用残缺数据覆盖上一次结果。
- 图片清理：超过 45 天未被刷新的本地图片自动删除（对应商品 / 资讯已下架）。
